# Abgeleitete Werte

| Wert | Formel oder Angabe im DOCX |
|---|---|
| Bewegung | Geschwindigkeit + Bewegungs-Bonus. Gibt Felder fuer die Aktion Laufen an. |
| Faehigkeitenplaetze | Gedaechtnis + Faehigkeitenplatz-Bonus. Zahl gleichzeitig ausgeruesteter Faehigkeiten. |
| Lebenspunkte pro Verletzung | (Vitalitaet x 5) + Lebenspunkt-Bonus. |
| Maximale Psyche | 2 x Willenskraft + Psyche-Bonus. |
| Ausweichen | 1 + Ausweichen-Bonus. |
| Maximale Stabilitaet | 2 x Koerper + Stabilitaets-Bonus. |

Die Abschirmung wird an anderer Stelle ebenfalls Koerper zugeordnet. Ob Abschirmung und Stabilitaet getrennte Werte sind, ist offen: [[Werkstatt/Widersprüche/Widersprüche|W-001]].
